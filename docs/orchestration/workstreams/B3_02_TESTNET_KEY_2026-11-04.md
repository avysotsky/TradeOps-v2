## Corrected by real qualification

GET requests carried JSON in a body which the live endpoint did not accept, and
connection-scoped authentication was reused between HTTP requests. This was found
before any order action. The tool now uses JSON-RPC POST, a unique REST session
with requested 300-second expiry, exact session validation and a bounded lifetime.
Private WSS capture keeps its own existing read-only connection scope unchanged.

Tests assert the HTTP verb and requested session/expiry and reject connection or
mismatched-session grants. The real key preflight separately confirmed the corrected
wire behavior. **134/134 PASS**, 0 failed/skipped; case time 107.0584 seconds.

are checked before publication. Release build: 0 errors, 15 pre-existing analyzer
warnings; versions, schemas, container resources and neighboring services unchanged.
